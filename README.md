# Distributed Network Slicing Platform — Milestones 1–4

Open this folder in VS Code.

Install:
`pip install -r requirements.txt`

Run:
`python run_demo.py`

The demo starts one controller and two worker services locally, demonstrates the first four milestones, and writes `results/milestone_results.json`.

This is a prototype for demonstrating the milestone concepts. It can later be deployed across the master/node1/node2 VMs and extended with databases, Kafka/Spark, dashboards, containers, stronger consensus and failure recovery.
